# 俄罗斯方块

一个用 HTML5 Canvas 写的极简俄罗斯方块，单文件、零依赖，直接用浏览器打开 `tetris.html` 即可游玩。

## 功能

- 开始 / 暂停 / 继续 / 关闭
- 得分显示与实时状态提示
- 消除行计分（连消翻倍）
- 键盘操作，七种方块不同配色

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 加速下落 |
| ↑ / W | 顺时针旋转 |
| Q | 逆时针旋转 |
| 空格 / P | 暂停 / 继续 |
| Enter | 开始游戏 |

也可以直接点击页面下方的「开始游戏」「暂停」「关闭」按钮。

## 运行

无需安装任何依赖，双击打开 `tetris.html`，或在本目录启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000/tetris.html 。
